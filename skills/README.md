# OpenMaic 质性研究方法学习 Skill 打包清单

> 打包日期：2026-10-14
> 作者：富驰华
> 内容：在 OpenMaic 质性研究方法课程（及学习研究方法）中沉淀的可复用 Skill，共 10 个，与创业/商业方向无关。

## 一、质性研究"问题与设计"层

| Skill | 目录 | 说明 |
|---|---|---|
| 质性研究问题引导 | qualitative-question-guide | 提出、打磨并检验一个"好"的质性研究问题 |
| 研究取径选择与论证 | qual-research-approach-guide | 判断用哪种研究取径并写出说服性论证 |
| 研究设计引导 | qual-research-design-guide | 研究情境/对象/进入/资料（倒置螺旋锥体+三分钟草图） |

## 二、质性"数据收集"层：访谈与观察

| Skill | 目录 | 说明 |
|---|---|---|
| 访谈前准备顾问 | qual-interview-prep | 访谈大纲、主题指南、追问路线、伦理 |
| 访谈后复盘顾问 | qual-interview-review | 复盘访谈过程、评估质量、整理数据 |
| 观察法设计顾问 | qual-observation-design | 观察=观+察、价值前见、6W、观察表选型 |
| 观察复盘总结 | qual-observation-review | 将观察记录生成总结报告 |

## 三、质性"团体研究"层：焦点小组

| Skill | 目录 | 说明 |
|---|---|---|
| 焦点团体设计 | focus-group-designer | 从零设计焦点团体访谈方案 |
| 焦点团体复盘 | focus-group-debrief | 对主持过程做结构化复盘 |

## 四、学习方法与学术转化

| Skill | 目录 | 说明 |
|---|---|---|
| 课程学习与研究转化工作流 | course-learning-workflow | "两批制（先粗后细）"学习模式 |

## 关联说明

- 本批 Skill 与作者在 OpenMaic 课程中的"提问式学习、质性方法沉淀"闭环一致。
- 创业方向 Skill（opc-bp-writer）与业务工具（mili-career-report、proposal-rework-collab）不在本包内。
- 各 Skill 完整内容含 `references/` 参考文件；本仓库以 SKILL.md 为主上传，完整 references 见论文课程论文目录的本地打包 `OpenMaic学习Skill打包.zip`。
