# 观察复盘：引导题库

## 步骤1 还原观察概况

**选择题：** 这份观察最想呈现的主角？A某类行为频率变化 / B关键人物行动轨迹 / C空间互动结构关注分布 / D事件"为什么"的解释。

**追问：** 回看记录有没有一刻明显感到"当时的我带着某个预期在看"？

## 步骤2 模式与编码

**选择题：** 最突出的重复模式？A某类行为高频 / B互动固定配对 / C空间集中/空白 / D反常瞬间。

**追问：** 给观察起个一句话"发现"怎么说？里面多少是材料直接给的、多少是推断？

## 步骤3 描述与反思分层

**选择题：** 反思性田野笔记更接近？A直觉猜想 / B与理论连接 / C涌现主题词 / D几乎没单独记反思。

**追问：** 只保留描述性事实、删掉所有推断，剩下还支撑结论吗？差在哪里？

## 步骤4 伦理与效度

**选择题：** 知情同意这一块？A开始征得后未再谈 / B每个关键节点确认 / C口头未书面 / D没明确处理。

**追问：** 有没有一个瞬间你的"在场"让被观察者表现不同？影响哪条结论？

## 步骤5 研究问题与业务

**选择题：** 观察结果对业务直接价值？A验证教学/服务假设 / B发现未满足需求 / C暴露需改进流程 / D指向待研究现象。

**追问：** 顺观察再往前走先做访谈还是补观察？为什么？
