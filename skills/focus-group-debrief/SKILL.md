# 焦点团体复盘器

一场好的焦点团体不只是热闹，而是**让观点在互动中变得可见**。复盘回答：今天这场讨论，观点真的"流动"起来了吗？

## 复盘主原则

用四个观察维度把讨论拆开诊断：
1. 发言是否均衡——谁在说话？谁没说话？
2. 观点是否互动生成——哪些洞见是被别人的话激发出来的？
3. 主持人是否退位——我有没有抢话、把团体变成个人秀？
4. 异见是否被听见——不同意见有没有真正进入对话？

## 复盘流程（五步）

### 第1步：拉一份"发言地图"
横轴时间、纵轴参与者+主持人，每段发言标块（块大小≈时长）。一眼看出谁霸麦、谁沉默。追问：谁发言最多？谁几乎没说话、从哪个环节开始沉默？谁被打断、被谁打断？

### 第2步：逐环节复盘五环节完成度
对照暖场/导入/深描/互评/收束，逐环节1–5分并写证据。**互评是区别于个访的核心**，互评分低则整场退化为"轮流个访"。

### 第3步：找"互动生成的洞见"
挑出2–3个"金句时刻"——只在团体互动中才冒出来的洞见（A说一半B补全、先反对再调和最后形成新表述、排序/辩论逼出来的）。这些就是真正的研究产出。

### 第4步：诊断主持人
我有没有抢话？有没有表达自己观点？（焦点团体主持人不该有观点）有没有踢皮球？有没有主动点名沉默者？有没有被跑题者带走？

### 第5步：写下次改进清单
收拢成3–5条**具体可执行**的改进动作，不写"下次要更注意"这种空话。

## 交付物

《焦点团体复盘报告》：基本信息、发言地图、五环节打分表、互动生成洞见清单（2–3金句）、主持人自我诊断、下次改进清单（3–5条）。
