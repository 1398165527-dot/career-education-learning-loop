# 访谈提纲示例（做减法/排序/演练时可对照）

## 示例一：返乡创业研究（问题列表→主题指南转化）

反例·问题列表：你什么时候回来的？你父母支持吗？你女朋友没阻止吗？…

正例·主题指南（四个主题区域）：返乡决策过程 / 创业实践细节 / 社会关系网络变化 / 自我认同与意义感。要点：受访者从"创业实践"跳到"和父母吵架"，只要属于"社会关系变化"就让他讲下去。

## 示例二：大学教师"只想当普通教师"研究

研究情境：绩效管理至上时代，为什么相当一部分老师只想当"普通教师"？受访者：四十多岁女性大学教师。

| 主题板块 | 核心触发问题 | 追问方向 |
|---|---|---|
| 1 基本情况 | 聊聊教龄、学科和职称 | 细节：日常一周工作节奏 |
| 2 工作身份定位 | "普通教师"是什么意思？ | 意义/对比：和刚入职比身份感觉 |
| 3 "辞编"目标 | 念头什么时候、怎么冒出来？ | 细节/情感：下定决心的瞬间、心里滋味 |
| 4 单位管理方式 | 学校怎么管理编制内教师？ | 细节：绩效考核具体怎么操作 |
| 5 目标与制度张力 | 目标和绩效管理有没有别扭？ | 对比/努力 |

排序说明：基本情况开场，身份定位、目标居中，管理方式与制度张力偏后。

## 示例三：青椒"教学与科研如何兼顾"（角色扮演练习）

主题指南：教学日常/科研日常/冲突场景/应对策略与代价/意义感。核心触发："在您一周时间表里，教学和科研各占什么位置？"

## 使用提示

每份提纲控制在5~6个主题板块，少而精。敏感话题放中后段。演练时把书面语改口语。
