# 引导题库：情境化选择题 + 开放式追问

按环节组织。每个环节先给情境化选择题，再给开放式追问。不要一次抛完——每个环节取1道选择题+1~2个追问。

## 步骤0 定位与范式

**选择题：** A听懂某个人的人生故事（叙事）/ B抓住一群人共同体验本质（现象学）/ C从资料长出一个理论（扎根）/ D浸入一个群体文化（民族志）/ E深入解剖有边界的系统（案例）。

**追问：** 用一句话说你想研究的现象？你心里最想弄明白的"为什么"指向哪种范式？

## 步骤1 研究情境（在哪做）

**选择题：** A熟悉的地方（便利但太熟看不清）/ B完全陌生的地方（客观但进入成本高）/ C现象最密集的地方（信息量大但难进入）/ D线上混合场域。

**追问：** 为什么这里最能看见问题？场域边界在哪？进入难度多大、谁会给你开门？

## 步骤2 研究对象与抽样

**选择题（关系）：** A亲历者 / B行动者 / C见证者 / D关键知情人。

**追问：** 谁是你的样本、为什么？（"有关"换成"能提供关键经验行动解释"）纳入谁排除谁？打算抽多少人、多少算合适？样本一次定死还是随研究调整？

## 步骤3 进入路径

**选择题（方式）：** A正式许可 / B关键联系人引荐 / C滚雪球 / D直接进入公开场域 / E线上入口。

**追问（权力距离）：** 你和对象间有哪些权力距离？不对等怎样影响他们愿意说什么？

**追问（身份）：** 你是内部人还是外部人？各自利弊与对资料的影响？

**追问（伦理）：** 怎样向对象说明研究目的、资料使用、可随时退出？隐私/匿名/录音/敏感信息/关系压力如何处理？

## 步骤4 资料与保存

**选择题：** A访谈转录 / B田野笔记观察 / C文档档案实物 / D在线质性数据 / E照片启发。

**追问：** 这些资料分别回答问题哪部分、够不够交叉验证？怎样组织命名做到可追踪可保护可分析？

## 步骤5 闭环检查

四问检查 + 一句话公式（我将在什么情境中，接近什么对象，通过什么方式进入，并收集什么资料）。
