# 设计蓝图：数据收集环 / 倒置螺旋锥体 / 三分钟草图 / 四问检查 / 一句话公式

## 1. 数据收集环

质性数据搜集是一个环：定位现场/个体 → 目的性抽样 → 获得进入并建立关系 → 收集数据 → 记录信息 → 处理田野问题 → 存储数据 → 回到定位，循环往复直到资料饱和。情境、样本、进入方式都不是一次定死，每转一圈修正定位。

## 2. 倒置螺旋锥体 × 三分钟研究设计草图

### 倒置螺旋锥体（研究问题居中）
研究设计以研究问题为中心，目的/情境/方法/效度四要素围绕中心逐圈收拢，层层指向核心问题。本Skill负责"情境"这一圈，即让场域与问题互相定义。

### 三分钟研究设计草图（快速定位）
一句话现象 / 一个现场（研究情境）/ 一类对象（研究对象）/ 两种资料（收集什么）/ 一个风险（最大伦理/进入/效度风险）。五问与四环节一一对应，可快速检验设计是否成形。

## 3. 四问检查

1. 我的研究情境是什么？为什么这里最能看见问题？
2. 我的研究对象是谁？纳入和排除的标准是什么？
3. 我如何接近他们？可能存在哪些权力距离和伦理风险？
4. 我将如何保存资料，并保护参与者隐私？

## 4. 一句话公式

> 我将在什么情境中，接近什么对象，通过什么方式进入，并收集什么资料。

## 5. 《研究情境与对象选择方案》输出模板

一句话现象/研究问题、研究范式、研究情境（场域/为什么/边界）、研究对象与抽样（角色界定/纳入/排除/样本量）、进入路径（方式/权力距离/内部人外部人/知情同意/伦理）、资料与保存（数据形式/保存方式）、一句话公式。
