# 课程学习与研究转化工作流

将课程学习从"被动听课"转化为"主动研究"的完整工作流。采用**两批制（先粗后细）**：先把课件全部录入并给出大致想法，生成第一批初稿；之后复盘，复盘结束再在原文件基础上更新为修订版。

## 工作流总览

```
阶段A：课件录入 → 阶段B：首批生成 → 阶段C：复盘引导 → 阶段D：文件更新 → 阶段E：产物存档
(全部课件+想法)   (告知拍完→出初稿)  (复盘所有已学+细节思考)  (更新为修订版)  (归档到电脑文件夹)
```

**两批制核心原则**：第一批（初稿）在全部课件录入后一次性生成五份主体产物（+条件性产物六）；复盘引导（后细）在用户回来时做细节思考；文件更新覆盖原文件、不另起炉灶。阶段E（本地存档）为必做步骤。

## 产物清单

- 产物一 课程完整笔记（HTML）
- 产物二 思维地图（HTML）
- 产物三 Word版研究设想（.docx）——统一用"倒置螺旋锥体×三分钟研究设计草图"框架：先中心研究问题，再逐圈展开目的/情境/方法/效度，每个课题先过五问草图
- 产物四 疑问解答与理论延伸档案（HTML，跨课程累积）
- 产物五 学习板块连接档案（HTML，跨课程累积）
- 产物六 自媒体选题与稿件构建档案（HTML，条件生成）
- 引导式学习记录（HTML）

## 阶段A：课件录入
只记录确认、不生成产物；记录用户想法、待学问题、自媒体选题方向（保留原话）；用户告知"全部课件已录入"后进入阶段B。

## 阶段B：首批生成（先粗）
基于大致了解一次性生成五份初稿（+条件性产物六）；研究设想按螺旋锥体框架组织；标注"首批/初稿"；present_files交付+阶段E存档。

## 阶段C：复盘引导（后细）
复盘本项目所有已学内容；用情境化选择题+开放式追问做细节思考；串联跨板块连接；记录素材；留存"引导式学习记录"；一次一步、尊重节奏。

## 阶段D：文件更新（修订版）
在原文件基础上并入新思考更新为修订版；覆盖更新、不另起炉灶；跨课程累积档案按规则并入；交付+存档。

## 阶段E：产物本地存档（必做）
存档根目录：`/Volumes/米粒学业/open maic 学习项目/课程学习档案/`。目录结构：01_课程资料/课程NN_主题、01_课程产出、02_方法与思考、03_研究课题、04_过程文件、04_原始材料、05_疑问解答与理论延伸、06_板块连接。文件命名：`课程NN_主题_内容_版本.扩展名`。课程编号从01起（现有人力资本/因果推断/教育理论与政策/个性化学习/皮亚杰维果斯基/社会生态背景，新课程顺延）。

## 关键注意事项

不跳录入与复盘；忠实记录原话；理论扩展要标"扩展理论"；课题可落地；研究设计"研究问题居中"；关联用户业务；产物间保持一致；存档优先；跨课程累积档案先读历史再并入；两批制覆盖更新；引导记录留档；自媒体档案条件生成。
