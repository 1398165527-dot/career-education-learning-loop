# 选择决策框架

## 问题性质→取径映射表

| 问题性质 | 首选取径 |
|---|---|
| 个体经历/身份/意义 | 叙事研究 |
| 体验的本质 | 现象学 |
| 过程/互动/机制 | 扎根理论 |
| 文化共享群体 | 民族志 |
| 有边界的系统/事件 | 案例研究 |
| 话语与权力 | 话语分析 |
| 实践改进/改变 | 行动研究 |

## 四维核对清单

1. 问题：需要什么取径？2. 对象：特征偏好/排除哪些？3. 资料：形态支持哪些？4. 产出：一致吗？

收敛规则：保留 2~4 种候选；四维都匹配→强候选；三到四维不匹配→剔除。

## 决策要点

问题优先；不追求纯正归类；资料可行性是硬约束；产出一致性；"为什么不是其他取径"想具体；关联用户业务。
