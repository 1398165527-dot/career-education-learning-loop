# 研究取径论证：模板与自检

## 论证模板（问题-对象-资料-产出）

```
我的研究问题关注____，因此需要一种能够____的取径。
研究对象/场域具有____特征，适合采用____研究。
我将收集____资料，并通过____分析来形成____产出。
与____取径相比，____更适合本研究，因为____。
```

最后一句"为什么不是其他取径"是论证核心。

## 四问自检

1. 是否说明问题核心性质？2. 是否解释为什么不是其他相近取径？3. 资料来源是否匹配？4. 预期产出是否一致？

核心标准：问题、资料、产出三者互相支撑、内在一致，论证成立。

## 写作要点

问题一句点透；对象讲特征而非名字；资料与产出配平；"为什么不是其他"要具体（拿对比差异）；承认边界模糊。
