# 质性研究问题框架速查

## 1. 四者之辨

| 概念 | 定义 | 例子 |
|---|---|---|
| 现象 | 观察到的客观存在 | "越来越多年轻人选择不婚" |
| 问题（困难） | 现象让你困惑、不解、不安时内心的张力 | 见杜威 |
| 题目 | 研究的标题 | "青年不婚现象研究" |
| 研究问题 | 驱动整个研究的核心追问 | "年轻人为什么在'该结婚'压力下仍选择不婚？" |

## 2. 问题从哪来

1. 个人兴趣与关怀 + 真实现实困惑；2. 文献空白与不足。最好研究问题 = 两者交汇点。特别关注针对常识性悖论发问。

## 3. 问题类型谱系

描述性（是什么样）/ 情境性（什么情境下需要）/ 差异性（不同对象做法有何不同）/ 意义性（对当事人意味着什么）/ 过程性（如何形成）。取向：描述性 / 解释性 / 分析性。

## 4. "好"问题五标准

1. 开放性；2. 聚焦性；3. 悖论性；4. 可研究性；5. 个人与公共关怀融合。核心理念"小题大做"。

## 5. 四大障碍

被理论绑架 / 被常识固化 / 被价值遮蔽 / 被焦虑驱动。

## 6. 五条突破路径

培养问题感 / 回到生活 / 浸泡文献 / 进行比较 / 追问"第一序列问题"。

## 7. 米尔斯《社会学的想象力》

三个主张：不迷信技术（让问题寻找方法）；坚持模糊形象并整理出来；具有问题意识。三维度：关于问题、关于方法、关于理论。

## 8. 培养社会学想象力三关键

生命激情 / 田野好奇心 / 理论浸泡与理性映照。

## 9. 打磨三关键维度

澄清核心概念定义；理清主问题与子问题逻辑；考虑对象抽样与可行性。
