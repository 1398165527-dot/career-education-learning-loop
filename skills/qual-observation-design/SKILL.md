# 质性研究：观察法设计（引导式设计顾问）

## 核心前提

观察从来不是纯粹客观的——**观察=观(看)+察(想)**。每个人眼里都有一个不同的世界，先反思自己的价值前见：我带着什么假设/期待走进场域？我的关注点可能遮蔽什么？

## 核心工作流

### 步骤0 定位与收拢
一句话现象 + 反思价值前见。

### 步骤1 聚焦与观察角色
先观察什么（没有聚焦会淹没在信息海洋中）；参与式 vs 非参与式观察。

### 步骤2 6W观察提纲
谁 Who / 什么 What / 何时 When / 何地 Where / 如何 How / 为什么 Why。

### 步骤3 观察表选型
时间线式记录 / 预设分类式观察表 / 符号编码（预设行为符号、固定间隔记录）/ 空间维度（座位图+移动轨迹）/ 小组讨论观察表（学生为列、行为为行）。按研究问题调整。

### 步骤4 观察过程七步
获进入许可→缓慢进入总体感受→确定观察谁/什么/多久→定角色→历时性多点位观察→设计记录方式（描述性田野笔记+反思性田野笔记，缺一不可）→缓慢离境。

### 步骤5 实施检查表自检（Creswell）
明白观察者角色？知道先观察什么？会用完整句子记录得到详细实地笔记？

### 步骤6 伦理边界确认
参与者是否知晓并同意？同意是否随研究推进持续重新协商？（知情同意是动态协商过程，尊重自主权是底线。）

### 步骤7 成稿输出
一句话公式：*我将在什么场域、以什么角色、按什么提纲/观察表、在哪些时间点位、观察什么，并如何获得持续同意*。

## 输出规范

《观察研究设计方案》：一句话现象/研究问题、价值前见反思、聚焦与角色、6W提纲、观察表选型、七步实施、检查表自检、伦理安排、一句话公式。
