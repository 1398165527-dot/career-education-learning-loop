# 观察法设计：引导题库

## 步骤0 定位与价值前见

**选择题：** A全程旁观记录 / B参与活动边做边看 / C先闲聊建立关系再记录 / D不确定。

**追问：** 如果换成完全陌生的人看，他最可能注意到什么？你现在最可能注意到什么？差别说明了什么？你心里有没有预期剧本？

## 步骤1 聚焦与观察角色

**选择题：** A立刻掏表逐格填写 / B先四顾感受整体再做有限笔记 / C直接找关键人物访谈 / D先定参与者还是旁观者。

**追问：** 如果只能聚焦观察一个东西选什么、为什么？参与式观察有什么信息优势与记录困难？

## 步骤2 6W提纲

**选择题（以"谁"为例）：** A谁在场身份角色 / B互动方向对象 / C谁缺席沉默退出 / D谁被关注忽视。

**追问：** 6W里只认真打磨两个维度选哪两个？"为什么"怎么问才不滑向主观臆断？

## 步骤3 观察表选型

**选择题：** 需比较不同小组讨论参与差异，最适合？A时间线 / B预设分类 / C符号编码 / D小组讨论观察表。

**追问：** 符号编码会牺牲掉什么？空间维度捕捉什么文字捕捉不到的东西？

## 步骤4 实施七步

**选择题：** 刚获准进班第一节课更应？A四顾感受做有限笔记 / B立刻逐条记录 / C先建关系 / D记下每个细节。

**追问：** 描述性/反思性笔记各最易缺哪部分？历时性多点位对你的课题意味着什么、打算观察几次？

## 步骤5 检查表自检

**选择题：** 三点哪点最易成短板？A明白观察者角色 / B知道先观察什么 / C用完整句子记录。

**追问：** 检查表里"避免故意欺骗"——哪些看似无心的做法可能滑向欺骗？

## 步骤6 伦理边界

**选择题：** 知情同意你更倾向？A一次签字 / B贯穿全程动态协商 / C口头即可 / D观察不需要同意。

**追问：** 发现参与者开始不自在怎么处理"继续观察"与"尊重自主权"的张力？中途想退出设计里有没有留空间？
