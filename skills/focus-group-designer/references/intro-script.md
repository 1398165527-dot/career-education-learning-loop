# 四段式开场介绍辞模板

介绍辞不是寒暄，而是设置研究关系与伦理边界。

## 四段结构
| 段 | 功能 | 关键要素 |
|---|---|---|
| 第一段 | 欢迎+自我介绍+说明团体目的 | 建氛围/身份透明/知情同意 |
| 第二段 | 说明团体成员特征 | 强化共同身份感 |
| 第三段 | 表明态度与立场 | 心理授权+录音保密（最关键） |
| 第四段 | 过渡到讨论 | 自我介绍+开放问题 |

## 第一段
模板："各位上午好，感谢加入今天的讨论。我是[名字]，我们受[委托方]委托，来了解[群体]对[主题]的看法。"

## 第二段
"之所以邀请你们，是因为你们都[共同经历]，我们想了解[你们的体验/看法]。"

## 第三段（最关键）
心理授权："这里没有标准答案没有对错，希望大家表达不同观点——不同意见恰恰是我们最想听到的。"
录音保密："今天会录音，只为整理不遗漏。整理成报告不会出现任何真实姓名，都会匿名化处理。"

## 第四段
"我们现在开始，先请每人用一两句话自我介绍——我是谁，以及[与主题相关的开放问题]。"

## 自检清单
第一段说清委托方与目的？第二段点出共同经历？明确说没有对错？主动说录音并承诺匿名保密？第四段真用开放问题启动？整段控制在3–5分钟？
