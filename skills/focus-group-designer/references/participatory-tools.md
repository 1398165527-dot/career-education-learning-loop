# 参与式活动工具箱

参与式方法的本质：让每个个体真正参与到群体活动中、与他人合作交流。无固定单一形式，可灵活创造。打破"你问我答"，通过具体活动产生真实互动。参考：《参与式学习指导手册》《在参与中学习与行动》。

## 工具速查表

| 工具 | 适合环节 | 解决 | 操作要点 |
|---|---|---|---|
| 画图 | 导入/暖场 | 降紧张、表达难言的第一印象 | 给纸笔限时3–5分钟不求画得好 |
| 排序/打分 | 深描/关键 | 排优先级、制造观点碰撞 | 每人独立排序后全组对比 |
| 便签头脑风暴 | 导入/深描 | 让沉默者贡献、避免健谈者带跑 | 先独立写→贴墙→归类→讨论 |
| 案例分析 | 深描 | 用具体情境代入抽象议题 | 给200字案例让大家评理 |
| 角色扮演 | 深描/互评 | 暴露立场差异、让观点被体验 | 分配角色3分钟即兴 |
| 辩论 | 互评 | 把分歧显性化 | 临时分组正方反方3分钟对辩 |
| 图片/卡片分类 | 导入/深描 | 把模糊感受变可操作分类 | 准备词卡让大家归类说理由 |
| 分组讨论 | 深描 | 大组里害羞者不敢说 | 4–8人拆2–3人小圈5分钟再回大组 |
| 运用想象/假如 | 收束 | 激发建议愿景 | "假如你是主办方会怎么做" |
| 一句话活动 | 收束 | 补遗漏抓最凝练声音 | 每人说一句最想说但没说的话 |

## 使用原则

1. 活动服务研究问题，不图热闹——每个活动结束问"让我们看到了什么"。2. 先个人后团体（先独立写/画2–3分钟再讨论）。3. 材料越简单越好。4. 主持人忍住不评判，只记录。5. 时间盒：写清几分钟到点就收。
