# 自建方法 Skill 索引

本目录收录米粒老师在质性研究方法课程（OpenMaic）学习中沉淀的 13 个方法 Skill，服务"从问题出发→解决真实问题→开拓线索→明确产品方向"的学习闭环。

| Skill | 定位 |
|---|---|
| course-learning-workflow | 课程学习与研究转化工作流（两批制：录入→生成产物） |
| qualitative-question-guide | 提出、打磨并检验一个好的质性研究问题 |
| qual-research-approach-guide | 选择研究取径（叙事/现象学/扎根/民族志/案例/话语/行动）并写出论证 |
| qual-research-design-guide | 质性研究设计：研究情境、对象与抽样、进入路径、资料收集保存 |
| qual-interview-prep | 质性访谈前准备：提纲、主题指南、追问路线图、伦理 |
| qual-interview-review | 质性访谈后复盘：评估质量、整理数据、改进 |
| qual-observation-design | 质性观察法设计：观+察、6W、时间线/分类式提纲 |
| qual-observation-review | 质性观察复盘总结：观察记录→可分析结论 |
| focus-group-designer | 焦点团体访谈完整方案设计 |
| focus-group-debrief | 焦点团体主持过程结构化复盘 |
| opc-bp-writer | AI 时代一人公司（OPC）商业计划书写作 |
| mili-career-report | 米粒生涯规划报告（生命数字·大学入学规划 H5） |
| proposal-rework-collab | 业务方案重构为面向合作对象的对接提案 |

这些 Skill 与课程论文《新高考下高中生生涯选项集的社会框定与教师中介》的方法论同源：以真实问题为起点，把质性研究设计、访谈与观察方法沉淀为可复用工具。
