# 生涯教育学习闭环 · Career Education Learning Loop

> 米粒老师（生涯规划与学习力咨询实践研究者）在质性研究方法课程（OpenMaic）中的学习闭环沉淀。

我的学习方式始终围绕一个核心：**从问题出发，想要解决真实的问题**。本仓库把这种学习方式沉淀为可复用的方法 Skill 与说明，既是我个人学习与实践的闭环记录，也作为课程论文《新高考下高中生生涯选项集的社会框定与教师中介》中"研究者学习与实践闭环"的佐证材料。

## 学习闭环理念

不是先学知识点，而是始终以"我正在面对的真实问题"为起点：

1. **从问题出发** —— 先问清楚"我想解决的真实问题是什么"，再谈方法；
2. **解决真实问题** —— 把问题转化为可操作的研究设计、咨询动作或产品原型；
3. **开拓新的线索** —— 在解决问题的过程中，不断发现新问题、新材料、新方法，让视野随之拓宽；
4. **明确产品与规划方向** —— 每一轮学习都指向下一步的产品方向与自己的人生/职业规划方向。

这个闭环，与我在课程论文中的核心机制"**真实问题触发**"是同一件事：一个真实问题（我想被理解、想找到知己）成为窗口开启的触发点，教师接住它、使其指向新的可能。

## 与课程论文的联结

论文以**自我民族志**方法回答："一个高中生的生涯选项集如何被结构框定？教师能否、在什么条件下成为松动这一选项集、把学科变成学生看世界窗口的人？"其方法论（质性研究设计、访谈、观察）与贯穿全篇的"真实问题触发"机制，正是本仓库所沉淀的同一套学习闭环的产物。本仓库因此不仅是学习记录，也是论文方法来源的证据。
